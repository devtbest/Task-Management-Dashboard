Task Management Dashboard

A responsive task management dashboard built with HTML, CSS, and JavaScript to help users organize tasks, track priorities, monitor progress, and stay focused on their goals.

## 🚀 Live Demo

[View Live Demo](https://devtbest.github.io/Task-Management-Dashboard/)

## 📸 About the Project

The Task Dashboard is a frontend project designed to make task management simple and organized. Users can create tasks, assign priorities, set due dates, track completion status, and search or filter tasks based on their needs.

This project was built to strengthen my frontend development skills through practical implementation of JavaScript, DOM manipulation, browser storage, and interactive user interface features.

## ✨ Features

- **Create Tasks:** Add tasks with titles, descriptions, purposes, motivations, and growth checks.
- **Edit Tasks:** Update existing task details whenever needed.
- **Delete Tasks:** Remove tasks with a confirmation step.
- **Task Status Management:** Mark tasks as pending or completed.
- **Priority Levels:** Organize tasks by high, medium, and low priority.
- **Due Dates:** Set deadlines to help manage tasks.
- **Dashboard Statistics:** View total tasks, high-priority tasks, pending tasks, and completed tasks.
- **Search Functionality:** Search tasks using relevant task details.
- **Filter Tasks:** Filter by all tasks, high priority, pending, or completed.
- **Sorting Options:** Sort tasks by newest, oldest, due date, or priority.
- **Local Storage:** Keep tasks saved in the browser after refreshing the page.
- **Toast Notifications:** Receive feedback when performing important actions.
- **Empty State:** Display a helpful message when no tasks match the current search or filter.
- **Responsive Design:** Use the dashboard across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic markup.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript (ES6+)** — Application logic, DOM manipulation, event handling, searching, filtering, sorting, and task management.
- **Local Storage API** — Persist task data in the browser.
- **Font Awesome** — Icons used throughout the interface.
- **Git & GitHub** — Version control and project hosting.

## 💻 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd task-management-dashboard
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
